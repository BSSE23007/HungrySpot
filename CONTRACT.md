# Implementation API contract (internal)

Core types are in Domain/Models.swift. Swift tools 5.7 / Swift 5 language mode / macOS 12 deployment. Public APIs below are synchronous and throwing unless indicated. Services compose a serialized database. UI is @MainActor; service authorization revalidates issued session token + persisted role.

Database(path: String), public url/path; execute(sql: String, parameters: [SQLValue] = []) -> Void; query(sql: String, parameters: [SQLValue] = []) -> [SQLRow]; scalarInt(sql: String, parameters: [SQLValue] = []) -> Int64; transaction<T>(_ body: () throws -> T) -> T; lastInsertID: Int64; backup(to: URL); close(); reopen(). SQLValue enum null, integer(Int64), real(Double), text(String), blob(Data). SQLRow helpers int(_), string(_), optionalInt(_), optionalString(_), double(_), data(_). All helpers use SQL column names.

Database.bootstrap() loads migration and seed SQL bundled in HungrySpotCore and seeds once. Schema owner publishes column names in DATABASE.md; service authors coordinate before using SQL.

AuthenticationService(database: Database): needsSetup() -> Bool; setupAdmin(username: String,password: String) -> Session; login(username: String,password: String) -> Session; logout(_ session: Session); authorize(_ session: Session, admin: Bool = false) -> User; users(session: Session) -> [User]; saveUser(session: Session,id: Int64?,username: String,password: String?,role: Role,isActive: Bool) -> User; changePassword(session: Session,currentPassword: String,newPassword: String).

CatalogService(database: Database,auth: AuthenticationService): categories(session: Session,includeInactive: Bool = false) -> [Category]; products(session: Session,search: String = "",categoryID: Int64? = nil,includeInactive: Bool = false) -> [Product]; product(session: Session,id: Int64) -> Product; setProductAvailability(session: Session,productID: Int64,isAvailable: Bool) -> Product; saveProduct(session: Session,product: Product) -> Product; duplicateProduct(session: Session,id: Int64) -> Product; deleteProduct(session: Session,id: Int64); saveCategory(session: Session,category: Category) -> Category; deleteCategory(session: Session,id: Int64); deal(session: Session,productID: Int64) -> Deal; saveDeal(session: Session,deal: Deal); settings(session: Session) -> AppSettings; saveSettings(session: Session,settings: AppSettings); audit(session: Session,limit: Int = 500) -> [AuditEntry]. AuditService(database: Database): record(userID: Int64?,action: String,entity: String,details: String).

PricingService(catalog: CatalogService): calculate(session: Session,draft: OrderDraft) -> Quote. Quote validation may accept empty customer data for live preview; OrderService.punch must require delivery customer name/phone/address. Empty carts can quote zero; punch rejects.

OrderService(database: Database,auth: AuthenticationService,catalog: CatalogService): punch(session: Session,draft: OrderDraft) -> OrderRecord; orders(session: Session,search: String = "",activeOnly: Bool = false,type: OrderType? = nil,payment: OrderPaymentFilter = .all,from: Date? = nil,to: Date? = nil,limit: Int = 200,offset: Int = 0) -> [OrderRecord]; order(session: Session,id: Int64) -> OrderRecord; transition(session: Session,id: Int64,to: OrderStatus,reason: String = "") -> OrderRecord.

PaymentService(database: Database,auth: AuthenticationService,orders: OrderService): pay(session: Session,orderID: Int64,method: PaymentMethod,amount: Money,cashTendered: Money? = nil) -> OrderRecord. CashPaymentQuote(total: Money,tendered: Money) throws exposes total/tendered/change/shortage/canConfirm. PakistanMobileNumber.normalized(_:) throws -> String and isValid(_:) -> Bool centralize delivery validation.

ReportingService(database: Database,auth: AuthenticationService): summary(session: Session,from: Date,to: Date) -> ReportSummary. ExpenseService(database: Database,auth: AuthenticationService): expenses(session: Session,from: Date,to: Date) -> [Expense]; add(session: Session,expense: Expense) -> Expense.

App-level infrastructure root-owned API: AppPaths() with root,databaseURL,images,backups URLs; ImageStorageService(paths: AppPaths) importImage(from: URL) -> String relative to images; url(for: String?) -> URL?; BackupService(database: Database,auth: AuthenticationService,paths: AppPaths) create(session: Session,destination: URL?) -> URL; validate(_ url: URL) -> String summary; restore(session: Session,from: URL,confirmed: Bool). PrinterService protocol printOrder(_ order: OrderRecord,settings: AppSettings,kitchen: Bool) throws; NativePrinterService implements it. Backup restore invalidates all sessions. Branding.jpg in app resources.

All service tests go in Tests/HungrySpotCoreTests and import @testable HungrySpotCore. No test should claim execution unless tool output verifies it. UI owner owns Sources/HungrySpot/Views and AppState.swift and HungrySpotApp.swift. Root owns Infrastructure and packaging/project/docs. Persistence owner owns schema/seed/catalog/security. Order owner owns pricing/order/payment/reporting/expenses and their tests.
