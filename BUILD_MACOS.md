# Build on the Intel Monterey laptop

Use the same macOS Monterey 12.7.6 / Xcode 14.2 / Swift 5.7 environment that ran the uploaded project. Package tools remain 5.7 and the minimum deployment target remains macOS 12.0.

## Build and open

Extract `HungrySpot-Monterey-cashier-update.zip`. In Terminal, change to its `HungrySpot` folder and run:

```sh
bash scripts/build-macos.sh
open 'build/The Hungry Spot.app'
```

The existing build workflow is preserved: `swift test --jobs 1`, then `swift build --configuration release --jobs 1`, followed by manual application packaging. On your Intel Mac this builds for the Mac's native Intel architecture. It stops on the first test or build failure. The output is exactly:

```text
build/The Hungry Spot.app
```

The old `.xcodeproj` remains for reference. Use SwiftPM and this script on Xcode 14.2; the owner reported that the project could not resolve its local HungrySpotCore product. Opening `Package.swift` is an alternative for source editing. Do not use the old DerivedData path.

The script copies the executable and resource bundles into the app. It also adds relative bundle links at the app root to satisfy the resource lookup generated by Swift 5.7. This avoids relying on an absolute path inside the original build folder. After building, copy the app to another folder, temporarily rename `.build`, and launch the copied app to confirm resources load independently. Restore the `.build` folder afterward.

Keep your existing restaurant data folder. There is no schema migration or reseeding in this update. Close the previous app before opening the updated one, since only one instance may open the store. Existing accounts and saved records remain in the original Application Support location.

## Optional DMG

```sh
bash scripts/package-dmg.sh --unsigned
```

This calls the same test/build script and stages `build/The Hungry Spot.app`. Signed distribution uses the existing `--signed` mode with DEVELOPER_ID and NOTARY_PROFILE configured on the Mac. Signing, notarization and DMG creation have not been run for this revision.

The optional GitHub workflow uses the same SwiftPM script. A current hosted Mac is not a substitute for verifying Xcode 14.2 and Monterey on your laptop.
